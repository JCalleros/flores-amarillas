# Flores Amarillas

Dedicatoria interactiva en 3D. Arrastra para girar alrededor del planeta, usa la rueda o pellizca para acercarte y lee las frases que orbitan a su alrededor.

[Abre Flores Amarillas](https://universo-flores-amarillas.vercel.app)

## Ejecutar en local

```sh
npm ci
npm run dev
```

Para compilar el sitio estático en `dist/`, ejecuta `npm run build`.
